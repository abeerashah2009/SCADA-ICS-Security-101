# Lab 03 - ICS/SCADA Terminology

## Overview

This lab introduces essential terminology used in Industrial Control Systems (ICS) and Supervisory Control and Data Acquisition (SCADA) environments.

The lab also compares ICS environments with traditional IT systems and examines real-world industrial applications.

---

## Objectives

- Understand common ICS/SCADA terminology.
- Identify the roles of PLCs, RTUs, HMIs, DCS and SCADA.
- Understand differences between ICS and traditional IT systems.
- Explore real-world ICS applications.

---

## Technologies and Concepts

- Industrial Control Systems (ICS)
- SCADA
- PLC
- RTU
- HMI
- DCS
- Smart Grid
- Water Treatment Systems

# Tasks Completed

## Task 1 - ICS/SCADA Terminology

Studied the following components:

| Component | Purpose |
|---|---|
| PLC | Executes real-time control logic |
| RTU | Collects and communicates remote field data |
| HMI | Provides operator visualization and control |
| DCS | Provides distributed process control |
| SCADA | Provides supervisory monitoring and data acquisition |

---

## Task 2 - ICS vs Traditional IT

Compared ICS and traditional IT environments based on:

- Real-time operation
- Safety
- Availability
- System lifecycle
- Physical process interaction
- Hardware
- Operational continuity

### Key Finding

ICS environments interact directly with physical processes. Therefore, safety, reliability, availability and real-time operation are critical considerations.

## Key Takeaways

1. PLCs perform real-time control tasks.
2. RTUs are useful for remote monitoring and control.
3. HMIs provide operators with graphical process information.
4. DCS distributes control across multiple controllers.
5. SCADA provides supervisory monitoring and data acquisition.
6. ICS environments have unique safety, availability and reliability requirements.
7. ICS technologies are widely used in critical infrastructure such as power and water treatment.
